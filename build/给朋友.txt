异潮 · ABERRANT TIDE —— 试玩说明
==================================

一、怎么打开（只要三步）
----------------------
1. 把收到的压缩包【整个解压】到任意文件夹（不要在压缩包里直接双击）。
   Windows 资源管理器里右键压缩包 →「全部解压缩」。
2. 解压出来只有一个文件：异潮.exe。双击它。
3. 等一两秒，会自动弹出一个游戏窗口，直接开始玩。

不需要安装任何东西，不需要联网，不需要打开浏览器，也不需要装 Java 或 Node。
游戏窗口就是程序本体，关掉窗口游戏就结束了，后台不会留东西。

第一次启动
----------
第一次运行会有一两秒准备（要把游戏本体从内存里展开），然后出现主菜单：
· 点「从一个细胞开始」进入游戏
· 第一次玩有七页教学，可以点「跳过说明」直接进
· 之后再来会多出「继续上次演化」，可以接着上次的进度

如果杀毒软件拦下来
------------------
这是用 Node 打包出来的程序，还没做代码签名，杀软误报很常见。
选「仍要运行 / 允许」即可，或者把它加进信任列表。

如果双击没反应
--------------
· 确认你解压的是完整的文件夹，而不是把 异潮.exe 单独从压缩包里拖出来。
· 右键 异潮.exe →「以管理员身份运行」试一次。
· Windows 防火墙第一次会问是否允许，允许即可（游戏只在本机跑，不联网）。

二、操作
--------
W A S D   游动
R / F     上浮 / 下潜
鼠标      环视（点一下锁定指针，ESC 释放）
左键      撕咬（需要先整合出「撕咬」本能）
Q         辐射脉冲（朝向前方的扇形）
Z         喷射突进（需要先整合出「突进」本能）
按住 C    拟态（需要先整合出「拟态」本能）
按住 X    感电扫描（需要先整合出「扫描」本能）
空格      冲刺 / 附着时脱离
G         附着（菌膜、宿主、反应堆、神经中继）/ 切断回声共振
E         摄食；贴身吞噬弱点；Lv.7 后在陆地上按 E 可以吃掉岸上的人类
M         异变记录（只读）
B         生命图鉴
J         海图
H         隐藏界面
ESC       暂停

三、这一版想让你看的
--------------------
· 岛上有日文招牌（排放站的告示、漁港名牌、商店街的「コンビニ」「そば」）、电线杆、
  塑料大棚、水田、神社石灯笼、自动贩卖机、红色邮筒、白色护栏。
· 港湾和巡逻舰上挂着日之丸旗。
· 岛的西北侧有一座火山锥。
· 上个版本加的五个本能（撕咬 / 突进 / 拟态 / 扫描 / 脉冲）和三座反应堆、
  排放母体、海洋之息都在。

四、给反馈的时候，这几件事最有用
------------------------------
1. 你拿到第一个"本能"（撕咬/突进/拟态/扫描）时，是什么感觉？
2. 三只异变回声体（折脊回声体 / 诱光群落回声 / 压力蠕冠）你卡在哪一只？
3. 海底黑不黑？菌膜找得到吗？
4. 海洋之息那个仪表，你看得懂它在说什么吗？
5. 一局大概玩了多久？在哪里觉得"没意思了"？
6. 有没有卡住、穿模、闪退？
7. 岛上的日文招牌、道路、街边那些小东西，哪一个让你一眼看出"这是日本"？

五、存档
--------
自动保存在你自己的电脑上（%APPDATA%\AberrantTide\ 里的浏览器存档）。
换电脑或清理浏览器数据会丢。
