# 《异潮》项目记忆



更新日期：2026-10-24。恢复开发时先读本文件、README.md 和实际代码；不要仅凭旧对话中的承诺判断功能已经实现。



## 桌面版打包（给外部试玩）：单文件 exe

用户要求"只给一个可执行文件，打开就玩"。最终方案是 **Node 的 Single Executable Application（SEA）**，不是 Electron：

| 文件 | 作用 |
| --- | --- |
| `scripts/make-single-exe.mjs` | 把游戏文件拼成自定义归档 → gzip → 加密 → 作为 SEA 资源内嵌 → 复制 node.exe 并用 postject 注入 blob |
| `scripts/verify-single-exe.mjs` | 把 exe 复制到无关目录双击，确认它自己解包、起服务、把游戏跑起来，且磁盘上没有明文源码 |
| `build/给朋友.txt` | 随包附带的操作与反馈说明 |

**成品**：`dist/异潮.exe`（91MB），打包成 zip 后 **38MB**。朋友解压后双击即玩。

### 运行方式

1. 启动器立刻派生一个**隐藏子进程**（`windowsHide`）去做实际工作，自己退出 —— 这样双击时控制台窗口只闪一下。
2. 子进程解密载荷，**只放在内存里**，直接从内存提供文件 —— 磁盘上不落任何源码（`%LOCALAPPDATA%\AberrantTide\` 里只有一个 address.txt）。
3. 用系统自带的 Edge/Chrome 以 `--app=` 模式打开游戏：没有地址栏和标签页，看起来就是原生窗口。找不到浏览器就退回默认浏览器。
4. 页面关闭时用 `sendBeacon('/quit')` 通知服务器退出，不留后台进程；另有 10 分钟无请求自动退出的兜底。

### 为什么不用 Electron 做单文件

Electron 的运行时（几百 MB 的 dll/pak）必须和 exe 并排，天然是一个文件夹，做不成单文件。Electron 版本仍然保留（`npm run pack:win`），适合"要原生窗口且不在乎体积"的场合。

### 踩过的坑

1. **Electron 运行时下不来**：postinstall 与 electron-packager 都去 GitHub 拉二进制，国内不通。解法是 `ELECTRON_MIRROR=https://registry.npmmirror.com/-/binary/electron/`；单文件方案完全不需要 Electron。
2. **`fs.cpSync` 递归复制会静默打死进程**：复制 electron 的 `locales` 目录时 node 直接以退出码 127 结束，零报错输出。改用自己写的逐文件 `copyTree`。
3. **加密要先压缩再加密**：顺序反了 exe 会胖 10MB（加密后的数据压不动）。
4. **内存里的文件键没有前导斜杠**，而请求路径有 —— 不统一会全部 404。

### 诚实说明

载荷的加密是**防随手翻一翻**，不是密码学意义上的保密：密钥就在 exe 里，有心人能提取。真要防内行，得上代码混淆或服务端化。

## 桌面版打包（Electron 备选方案）

用 Electron 做外壳：内嵌本地静态服务器，把游戏装进一个原生窗口，朋友双击 exe 就能玩，不需要装 Node、不开浏览器。

| 文件 | 作用 |
| --- | --- |
| `electron/main.cjs` | 外壳主进程：起服务器（端口 0，让系统分配空闲端口）→ 开窗口 → 载入游戏 |
| `scripts/build-desktop.mjs` | 手工组装 dist：拷 Electron 运行时 + 应用文件 + three 运行时依赖 |
| `scripts/verify-desktop.mjs` | 启动打包好的 exe，用 CDP 连进去，确认场景真的渲染了、没有报错 |
| `scripts/make-icon.mjs` | 生成图标：纯数学画 PNG，再包成 Windows 的 ICO |
| `build/给朋友.txt` | 随包附带的操作与反馈说明 |

命令：`npm run pack:win`（组装）、`npm run pack:zip`（再打成 zip）、`npm run verify:desktop`（验证）、`npm run desktop`（本地跑外壳）。

**两个坑**（都花了时间排查）：

1. **Electron 运行时下载不到**。electron 的 postinstall 与 electron-packager 都去 GitHub 拉二进制，国内不通。解法：设 `ELECTRON_MIRROR=https://registry.npmmirror.com/-/binary/electron/` 手动跑 `node node_modules/electron/install.js`；打包则完全不用 electron-packager，自己拼 dist 目录。
2. **`fs.cpSync` 递归复制会静默打死进程**。复制 `node_modules/electron/dist/locales` 时 node 直接以退出码 127 结束，没有任何报错输出。解法：改用自己写的逐文件 `copyTree`。

打包体积 143MB（zip），其中大头是 Electron 运行时；`three` 只带真正会加载的 `build/three.module.js`、`three.core.js` 与 `examples/jsm`（整目录都要，`postprocessing` 之间互相引用，还会用到 `../math/SimplexNoise.js`，只挑两个子目录会 404）。语言包只留 `zh-CN` 与 `en-US`，其余 53 个 .pak 省掉 49MB。

## V23：潮汐日、猎杀窗口与野外笔记

用户要求"大大提升可玩性，参考 Steam 好评游戏的玩法"。硬约束不变：**玩家不能选择进化路线**。
所以这一版提升的不是"内容量"，而是**决定的质量**。

### 1. 潮汐日（`src/tide.js`）
五分钟一个循环，四段各 75 秒：拂晓 / 正午 / 黄昏 / 深夜。每一段给出光照、捕食者察觉范围、
猎物垂直迁移、异变能收益四个系数。夜里异变最快，但捕食者最凶、视野最差——
"什么时候去哪"第一次成为真正的决定。渲染层只读这些系数（`scene.js` 的 `tideTint`、
`sun.intensity`、`ambient`、`motes`），规则本身在 Node 里可单测。

**踩过的坑**：第一版垂直迁移写成 `dy += tide.preyRise * 0.0025`（恒定推力），
`homeY` 从未赋值，于是所有鱼被一路推到水面上限，确定性通关测试种子 11 直接死亡。
改成围绕 `homeY ± preyRise` 的软约束后才恢复正常。

### 2. 猎杀窗口（`src/hunting.js`）
每种生物有一个"此刻可以下手"的破绽：
- 鱼群 / 灯笼鱼：**侧线盲区**（视野锥外命中，2.2×）
- 鲨鱼 / 原生捕食者：**扑空回身**（`recoveryUntil`，2.5×）
- 蟹：**蜕壳**（13 秒周期里 2.8 秒，3×）
- 水母、鮟鱇、鳐、海龟、墨鱼、皇带鱼、鱿鱼：各自的周期窗口（2.2–2.4×）

窗口是纯函数 `huntWindowAt(entity, time, player)`，AI 不需要额外记账。
伤害倍率接在撕咬、冲刺撞击、喷射突进、脉冲四个出口上。

### 3. 野外笔记（`FIELD_NOTES`）
第一次在窗口里命中某种生物，就解锁它的笔记（永久加成：破绽伤害、刷新冲刺、额外生物质、
窗口内免反伤）。图鉴新增"野外笔记"页签，未解锁的显示为"尚未记录的习性"。

### 4. 海洋之息机制化（`src/ocean-breath.js`）
账目不再只是结局分数：负值（猎杀路线）伤害 +35%、治疗 -45%；正值（共生路线）伤害 -12%、
治疗 +90%。"你要成为什么"由行为长出来，不由菜单选出来。

### 5. 开局三十秒
目标文案改成两条路的对比（蓝色羽流稳 / 橙色核心快但辐射与捕食压力上涨），
把"按 E"变成"选一条"。

### 验证
- `tests/tide.test.mjs`（7 项）、`tests/hunting.test.mjs`（6 项）
- `scripts/verify-v23.mjs`：浏览器内实测盲区 2.2×、蜕壳 3.5×、笔记解锁、潮汐系数
- `npm.cmd test` 165 项全过；`expedition-journey` 五种子仍全部通关

## V21–V22：让"这是日本"一眼看得出来 + 岛民美化

用户的原话是"我希望让大家都知道是日本，而且应该用日本地貌，然后海岛还需要美化海岛和人"。

### 不画国旗，改画日常

用户不确定要不要用真国旗，本轮决定**不立国旗**：国旗是国家的符号，画上去就是在喊话；而日文告示牌、渔船名、神社匾额、渔港名是"这个地方就是这样"的日常感。玩家看到「ALPS処理水 排出設備」会自己反应过来这在哪，比一面旗更有冲击力，也不会让作品变成一张传单。

唯一的例外是**日之丸旗**：挂在港湾旗杆和巡逻舰的桅杆上（小尺寸、需要凑近看），作为最后的确认，而不是主视觉。

| 文件 | 作用 |
| --- | --- |
| `src/japanese-marks.js` | canvas 画日文招牌（`signTexture`）、立式招牌、墙面告示、日之丸旗与旗杆。**Node 里没有 DOM 时返回 null**，单测不会炸 |
| `src/island-detail.js` | 电线杆与垂线、屋顶储水罐与空调外机、塑料大棚、神社石灯笼、水田、商店街、自动贩卖机、红色邮筒、白色护栏 |

岛上的日文：排放站「ALPS処理水 排出設備／海域モニタリング実施中」、危险告示「危険／放射線監視中／立入制限」、渔港「松浜漁港／漁業協同組合」、神社「奉納」、屏障「立入禁止／海域排出施設周辺」、商店街「お食事処／定食・丼物」「コンビニ／たばこ・お酒」「そば／十割」。

### 地貌

新增 `volcanoConeGeometry()`：带火山口的上陡下缓成层火山（指数小于 1 的半径曲线 + 游走的沟壑噪声 + flatShading），放在岛西北侧台地 `(-46,-40)`，深色玄武岩材质，顶部有暖色火口辉光和蒸汽片。原来的雪山脊保留，于是岛有两个峰：主峰 + 火山锥。碰撞面 `islandSurfaceAt` 未改 —— 地貌是**纯视觉**的，避免影响登陆判定与设施高度。

### 人

`src/human-models.js` 的围观人群从 7 个 instanced mesh 增加到 9 个：加了领口、反光背心、挎包，并按角色缩放帽子（工人黄安全帽、渔民宽檐帽、科学家鸭舌帽）。商店街与港湾的人站在街上，不是浮在空中的柱子。

### 新增文件

- `src/japanese-marks.js`、`src/island-detail.js`（新）
- `scripts/_shot22.mjs`（截图脚本，非产品代码）

### 坑

- `forEach` 回调里不能写 `continue` —— 改成 `return`，否则整页脚本直接抛 "Illegal continue statement"，游戏白屏。
- 相机朝向的约定：无论第一/第三人称，视线方向都是 `(-sin(yaw), -cos(yaw))`。截图脚本一开始按 `+sin` 算，镜头一直对着反方向。

## V20 技能成为主线的钥匙

用户试玩 V19 后确认了两个核心问题：**"技能没起作用"** 和 **"主线本身太短，要加厚"**。这两件事其实是同一件事 —— 技能如果不改变流程，玩家就感觉不到它。

### 每只回声体都有一把钥匙

`src/echo-system.js` 新增 `ECHO_RESIST`：

| 回声体 | 钥匙 | 用错工具的伤害 |
| --- | --- | --- |
| 折脊回声体（冲锋型） | 近战（撕咬／突进／冲刺撞击） | 脉冲 ×0.3 |
| 诱光群落回声（假光型） | 脉冲 | 撕咬 ×0.35 |
| 压力蠕冠（潜行型） | 感知（按住 X 扫描出真身，或按住 C 拟态引它过来） | 脉冲与近战都只有 ×0.35 |

伤害通道新增 `kind` 参数（`'pulse'` / `'melee'`），`_damageEcho` 按通道乘抗性；用对工具命中才计入"精准"评级，所以 1–3 级的追猎评级也反映了构筑。

**不设死锁**：冲刺撞击是近战，任何时候都能用；所以玩家永远有解，只是快慢差 3 倍。

### 母体的外甲挡得住辐射脉冲

触须的近战伤害 ×1、脉冲伤害 ×0.25。外甲阶段只有靠近身才撕得动。

### 本能来源分类保底

`_grantRandomInstinct` 改成**按来源分类保底**：捕食型（撕咬／突进）与共生型（拟态／扫描）各保证第一次必定成功。菌膜给共生型、猎杀给捕食型，因此主线上的三只回声体永远各有一条路可走。

### 主线加厚

- 回声体血量 100 → 140：对的工具要三个窗口，切断一次比原来慢一倍多。
- 冲刺撞击也走回声体的伤害通道（此前会把回声体直接打死而不净化）。
- 回声体的近身攻击冷却 1.7 → 2.4 秒：拉长战斗而不是拉长等待。

预计单局：菌膜+猎杀+宿主约 4 分钟，三只回声体 3–4.5 分钟，三座反应堆 3 分钟，母体 2–2.5 分钟，加移动约 3 分钟 —— 合计 15–18 分钟。

## V19 试玩反馈修复

用户实机试玩 V18 后给了六条反馈：整体"和以前区别不大"、海底太黑、菌膜找不到、变大后穿模、卡顿、不懂海洋之息、不能吃人类、直接走主线就结束。本轮逐条处理。

### 性能：模拟步耗时降到 1/3

`npm.cmd run bench:step` 是新加的基准。用 `--cpu-prof` 定位后改了四处：

| 改动 | 说明 |
| --- | --- |
| `distance()` 不再用 `Math.hypot` | hypot 为防溢出走慢路径，而它是模拟里最频繁的调用；换成平方求和 |
| 碰撞加"开阔水域"快速通道 | `farFromLand()` 用包围盒先排除岛屿/礁台/排放口/沉船，远处的动物不再每次都跑完整地理查询 |
| 反应堆碰撞不再遍历全部实体 | 改用生态索引（只有 3 个反应堆） |
| 排放口布局按 world 缓存 | `outfallLayout()` 之前每次碰撞都重算三次岸线 |

结果：**3.53 ms/步 → 1.09 ms/步**（鱼群密集时 0.71 ms）。另外把热路径上的临时对象分配去掉，环境的三角形密度降了约 14%（3.45M → 2.96M，远处被雾吃掉的部分不值得那么多面）。

### 穿模与卡住

碰撞体终于和看得见的身体一致了：新增 `playerBodyRadius()` —— 早期身体在世界里极小（本来就该在鱼群之间穿行），成为巨兽后身体才真正占据世界尺度。之前的写法两头都对不上：早期用世界尺度碰撞会撞上"看不见的墙"，成巨兽后只用 28% 视觉半径又会穿过鲨鱼和鲸。

### 深海可见度与导航

- 环境底光改成**按深度加权**：浅水保持原样，深海才提亮（避免浅水被洗白）。
- 菌膜自己会发光：加了生物光晕、远距离雾晕和点光源 —— 深海里这是玩家唯一的路标。
- 玩家自带光在深处更远更亮。

### 海洋之息改成看得懂

仪表从"一根条+一个数字"变成"一根条+一句人话"：海洋在好转 / 海洋略有余温 / 海还是那样 / 海洋在变冷 / 海洋正在死去。跨越 ±20 阈值时还会弹一条提示。

### 吃人类

站上灰屿但没有别的目标时，行动面板会明确显示"岸上掠食"，并说明 Lv.7 的门槛（之前只有一行夹在任务文案后面）。

### 第一个本能必定到手

菌膜是必经路径，它给的共生本能改成 **100% 成功**（之后才是 60%）。整局只用一个脉冲的玩家会觉得"和以前没区别"。

### 本能整合卡片

新技能解锁时弹一张居中卡片，写清技能名、作用和按键（`src/reveal.css`）。此前只有一行小字 toast。

### V18 最新状态：随机抵达的本能



用户实测认为 V17"不好玩"，根因是三条：12 级身体 0 次决策（随机演化）、13 个里程碑全是同一个读条动词、战斗是核弹且没有死亡压力（自动机器人两分钟通关）。用户确认了四个方向：能力**完全随机但随机结果解锁技能**、单局 15–20 分钟、玩法先行画面配合、**双结局由玩家行为决定海洋下场**。



本轮完成：



- **技能系统**（`src/instincts.js` / `src/instinct-ui.js` / `src/instinct.css`）：撕咬（左键）、喷射突进（Z）、辐射脉冲（Q，改 130° 定向扇形）、拟态（按住 C）、感电扫描（按住 X）五个主动本能，由 ASSIMILATIONS 与 MUTATIONS 随机绑定；脉冲是开局保底。每条两阶。**玩家没有任何指定接口**，技能只能随机抵达。

- **技能来源天然分流**：菌膜共生给共生型技能，猎杀给捕食型技能，辐射响应给强化型。因此构筑倾向自然对应结局。

- **遭遇分段**：菌膜 12 秒三段（稳定期招来捕食者）、反应堆三段入侵（压制期引来维护无人机）、寄生接入会被灰屿电网反击截断进度。全部提前 2 秒预警，可自由放弃。

- **排放母体**（`src/emissions-mother.js` / `src/mother-models.js`）：三阶段 Boss 取代原先的"靶子核心"。外甲三条触须（撕咬）→ 喷发污染云（脉冲/拟态）→ 核心窗口（撕咬/冲刺撞击）。触须是独立实体，母体死亡时一并清除。

- **辐射暴走**：剂量 ≥85 持续 2 秒进入 8 秒暴走，伤害 ×1.5 但持续掉血，结束时辐射降到 45 并额外给 26 异变能。

- **捕食者前摇**：扑击前 0.5 秒蓄势（`attackWindup` + `striking`），命中击退并触发"慌乱"；发光与冲刺扩大被发现半径，拟态相反。

- **海洋之息与三结局**（`src/ocean-breath.js`）：账目 = 共生 ×10 − 猎杀 ×2 − 近乎绝迹的物种 ×25。左上角有仪表。结局为共潮 / 灰烬 / 深渊之宴。环境即时反馈：账目越负，水越浑浊（复用分级 Pass 的 uPollution，零新增着色器），捕食者发现距离越长，鱼群回避越远。

## 操作、界面与保存



桌面鼠标自由环视，点击锁定，ESC 释放并暂停。WASD 随视角游动，R/F 升降，V 第一/第三人称，E 营养摄取或近距离吞噬终局核心，Q 脉冲，G 交互，J 海图，Space 冲刺或脱离。暂停提供灵敏度、反转垂直、减少动态与画质设置。触屏滑动环视，方向按钮移动。



主循环使用 FrameStepper 固定 60 Hz 模拟，画面对玩家、鱼群和全部动物的位置及朝向做插值；30、60、144 Hz 显示下的模拟结果一致，一次性按键不会因多子步重复触发。背景鱼群每个显示帧更新；鱼群不按距离降为 0.3 秒批次。鼠标视角直接更新朝向，第三人称相机跟随插值位置；第一/第三人称、反应堆遮挡和宿主体表锚点均有浏览器回归。
