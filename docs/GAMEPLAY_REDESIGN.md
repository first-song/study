# V18 玩法重构说明

> 本文记录 2026-10 起这一轮"让它好玩"的改动：为什么原来的流程无聊、现在怎么玩、代码在哪里。

## 一、原来为什么无聊

原版是一个能跑通全流程的可玩样片，但玩家几乎没有决策：

| 问题 | 代码位置 | 表现 |
| --- | --- | --- |
| 12 级身体，0 次决策 | `engine.js:_applyRandomEvolution()` | 每次升级纯随机抽一条分支，玩家既不能规划也赌不了 |
| 13 个里程碑 = 同一个动词 | `engine.js:_updateAttachment()` | 菌膜 8 秒、宿主 12 秒、反应堆 9 秒、寄生 6 秒 —— 全是"游过去 + 按住 G + 看进度条" |
| 战斗是核弹 | `engine.js:update()` 的脉冲分支 | 半径 14 的全向 AoE，5 秒冷却，贴着敌人按住就赢 |
| 没有死亡压力 | `engine.js:_updateEnemy()` | 捕食者只会直线冲；玩家 100+ 血对 7~16 点伤害 |

`docs/PROJECT_MEMORY.md` 里那句"自动控制器约两分钟可通关"，就是这些问题的量化结果。

## 二、现在的核心循环

```
观察  →  决定去哪 / 猎什么  →  用随机遇到的本能动手  →  海洋之息改变  →  下一幕
```

### 1. 技能是随机抵达的，但很有重量

新增 `src/instincts.js`。**玩家永远不能指定任何一条**，但每条都是能改变打法的新操作：

| 技能 | 键 | 随机来源 | 作用 |
| --- | --- | --- | --- |
| 撕咬 | 左键 | 吞噬甲壳类 / 辐射出膜棘 | 前摇 0.32s，朝前重创单体；命中蓄力中的回声体会打断它 |
| 喷射突进 | Z | 吞噬头足类 / 辐射出推进器 | 前方锥形喷水推进，撞开沿途生物 |
| 辐射脉冲 | Q | 开局保底；辐射转化强化 | 130° 定向扇形，击退 + 致晕 1.1s |
| 拟态 | 按住 C | 吞噬灯笼鱼 / 辐射出发光感知 | 收敛移动与发光，捕食者发现距离 ×0.12（对回声体只减半 —— 骗得过眼睛，骗不过共振） |
| 感电扫描 | 按住 X | 吞噬鳐鱼 | 60m 内生物轮廓与可攻击目标高亮 |

外加**冲刺撞击**：冲刺中撞到生物造成伤害与眩晕。冲刺从位移变成了招式。

三条独立来源保证全程有操作可玩：**菌膜共生**（共生型技能）、**猎杀**（捕食型技能）、**辐射响应**（强化型技能）。

> 技能来源天然区分路线：菌膜教你共生，猎杀教你捕食。构筑倾向会自然倾向对应的结局。

### 2. 每只回声体都有一把钥匙

技能不再是装饰，而是主线的钥匙：

| 回声体 | 解法 | 用错工具 |
| --- | --- | --- |
| 折脊回声体 | 贴近撕咬 / 突进 / 冲刺撞击 | 辐射脉冲只打得出三成 |
| 诱光群落回声 | 辐射脉冲打散假光 | 撕咬被假目标骗过，只剩三成五 |
| 压力蠕冠 | 按住 X 扫描真身，或按住 C 拟态引它过来 | 两种伤害都只有三成五 |

母体的外甲同样挡得住辐射脉冲 —— 触须只能靠近撕。**没有任何解法是死的**：冲刺撞击永远可用，所以玩家不会卡关，只是快慢差三倍。

> 你的构筑决定了你这一局会遇到什么麻烦：抽到撕咬就得贴身打，抽到脉冲就得拉开距离打。

### 3. 遭遇不再是读条

| 目标 | 原来 | 现在 |
| --- | --- | --- |
| 菌膜 | 8 秒读条 | 12 秒三段：摄取 → 菌落扩张 → 稳定；稳定期菌落的气味会招来捕食者，可硬撑也可脱离 |
| 反应堆 | 9 秒读条 | 三段入侵：注入 → 压制 → 过载；压制期维护无人机会来打断 |
| 寄生中继 | 6 秒读条 | 接入中段灰屿电网反击，进度被截断到 40%，需要重新维持 |

所有打断都**提前给出可读预警**，玩家可以自由放弃而不受惩罚。

### 4. 捕食者会蓄势

`engine.js:_updateEnemy()`：捕食者与无人机在扑击前有 0.5 秒前摇（`attackWindup` + `striking`），命中会把玩家推开并触发"慌乱"（移速 -15%）。冲刺可以甩开它。
玩家发光或冲刺会扩大被发现的半径；拟态则相反。

### 5. 辐射暴走：高风险高回报

剂量堆到 85 以上并持续 2 秒 → 进入 8 秒**暴走**：伤害 ×1.5，但每秒额外掉血。暴走结束时辐射随组织重构释放（降到 45），并额外获得 26 点异变能。
于是"去污染区刷器官"变成一个**主动的赌博**，而不是被动挨罚。

### 6. 排放母体：真正的三阶段 Boss

`src/emissions-mother.js` + `src/mother-models.js`。取代原先"被屏障保护的靶子"：

| 阶段 | 内容 | 逼你用 |
| --- | --- | --- |
| 外甲 | 三条触须是独立实体，必须切断 | 撕咬 |
| 喷发 | 不断吐出污染云，灼烧进入其中的生命 | 脉冲打散 / 拟态硬扛 |
| 核心 | 只在 7 秒窗口张开 | 撕咬 / 冲刺撞击 |

### 7. 海洋之息：三种收束

`src/ocean-breath.js`。左上角那根以零为中点的仪表，记着玩家这一局的账：

```
账目 = 共生里程碑 × 10  −  猎杀猎物数 × 2  −  被你打到近乎绝迹的物种 × 25
```

| 账目 | 结局 | 内容 |
| --- | --- | --- |
| ≥ +20 | **共潮** | 灰屿灯火熄灭，海水重新变蓝 |
| −20 ~ +20 | **灰烬** | 你赢了，但什么都没改变 —— 岛沉了，海还是死了 |
| ≤ −20 | **深渊之宴** | 你吞了岛，也吞了海洋；海水开始变黑，那是你 |

**过程中的即时反馈**（而不是等到结局才知道）：
- 猎杀越多 → 捕食者发现距离越长、鱼群回避半径越大
- 共生越多 → 反过来
- 账目为负 → 水色变浑浊（复用现有分级 Pass 的 `uPollution`，零新增着色器）

## 三、代码地图

| 文件 | 职责 |
| --- | --- |
| `src/instincts.js` | 5 个技能的参数、随机来源绑定、阶数查询 |
| `src/instinct-ui.js` / `src/instinct.css` | 技能条、未整合槽位的剪影、解锁高亮 |
| `src/emissions-mother.js` | 母体的三阶段状态机（纯模拟，不依赖 WebGL） |
| `src/mother-models.js` | 母体、触须与污染云的程序化模型 |
| `src/ocean-breath.js` | 账目计算、环境反馈系数、结局分类 |
| `src/breath.css` / `src/badges.css` | 海洋之息仪表与紧凑徽章 |
| `src/engine.js` | 技能执行、遭遇分段、暴走、顿帧、母体接入、三结局 |
| `src/scene.js` | 技能表现层（撕咬前冲、拟态材质、扫描轮廓）、屏幕震动、定向特效 |
| `src/ocean-breath.js` → `src/scene.js` | 生态崩坏度直接驱动水体浑浊 |

## 四、验证

```powershell
npm.cmd test                 # 单元测试
node scripts/verify-instincts.mjs   # 浏览器：技能条 / 撕咬方向 / 拟态 / 扫描
node scripts/verify-mother.mjs      # 浏览器：母体三阶段与污染云
node scripts/smoke.mjs              # 浏览器全流程回归（需服务已运行）
```

存档版本从 v9 升到 **v10**，v1–v9 全部自动迁移，新增字段（本能、账目、暴走、母体）都有兼容默认值。

## 五、仍然保留的原则

- 玩家**不选**进化路线、不买器官、不选卡。技能只能随机抵达。
- 吞噬的意义是"解锁一个新操作"，不是"多几滴数值"。
- 等级仍只由生态里程碑驱动；技能解锁**不给等级**，因此 12 次随机发育事件的既有保证不变。
