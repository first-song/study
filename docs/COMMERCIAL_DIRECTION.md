# 商业版本方向与当前边界

2026-10-16 用户纠正：目标是具有真实感的商业海洋生存游戏；拒绝稀疏生态、基础几何体拼接动物、按住鼠标才环视，以及玩家自选进化路线。已明确从单细胞出生，后续随机演化为更复杂的生命。

同日补充：海洋需要有辐射事件造成的异常个体与海底反应堆。用户认为反复吃颗粒、积满能量的循环过于接近贪吃蛇，要求玩法具有独立特点。本轮把成长条件改为有限的生态经历，把营养补给与身体发育拆开。

## 体验约束

- 海洋应呈现相互作用的生命。鱼群、游猎动物、漂浮生物与底栖动物在空间和行为上可区分。
- 鲨鱼、鲸等需要连续的身体、可辨识的头尾与鳍，动作来自身体推进与关节变化，不能仅把完整模型平移。
- 鼠标直接控制观察方向，锁定模式允许连续转向。暂停和图鉴必须释放鼠标。提供灵敏度、反转视角与减少动态设置。
- 随机演化不可被玩家指定。玩家只能应对已形成的身体，不能在升级时选一张牌、买一件器官或手工调节概率。
- 食物维持营养，辐射驱动异常变化，两种机制分别存在。随机结果有记录，存档保持随机序列连续。
- 正常与异常个体共存。异常通过轮廓、运动与行为差异呈现，并承担代价；不能仅加发光颜色就称为基因异变。界面以“异常生命”描述本作虚构表型。
- 观察环境、依附移动生物、把握污染源工作周期，应成为玩家主动决策的内容。进度来自完成一次生态行为，不能靠原地刷相同颗粒无限升级。

## 本轮可玩的循环

初生细胞在菌膜上附着消化，形成细胞协作；随后搭乘鱼、鲸或海龟，跟随宿主迁移并完成适应。发育后进入海底反应堆，在冷却窗口侵入管道，预警时撤离。侵入可分多个窗口累积，排放期继续附着会损伤生命并倒退进度。三座反应堆停止供能后，终局核心才解除屏障。

三个菌膜地点、三类宿主、三座反应堆分别记录首次完成状态。普通食物、猎物和已完成的附着地点仍承担生存补给，但不重复奖励发育。随机成长机制保留，用户选择的是行动和时机，不是器官、分支或概率。

异常鱼的弯脊、骨甲、异位诱饵表型既有可辨识形态，也有对应的游速、防护与攻击差异。反应堆的污染暴露进入动物模拟；冷却、预警、排放在场景和 HUD 中对应同一状态。图鉴解释这些表型的玩法差异，并标明快速重塑与强化器官是科幻设定。

这套循环目前用来验证“依附、借助迁移、侵入、撤离”的玩法是否成立。它仍有计时和进度条，不能据此宣称已经解决玩法新颖性或长期重复游玩的全部问题。

## 当前交付的性质

当前仍是本地可玩样片。连续网格、程序化材质、动态水体与生态数量的改进可以验证美术和玩法方向，但不能把它等同于完成了写实商业美术、完整内容制作或上市验证。

本轮新增动物、背景鱼群和环境表现由项目代码生成，未引入外部模型或图像。Three.js、Playwright 依赖与锁文件保持原有版本。商业分发前需要整理所发布依赖的许可证与归属信息；这里不代表已经完成分发审计。

## 下一阶段需要具体验收的工作

1. 选定目标平台、最低配置和目标画质，使用真实设备测帧率、显存、加载时间和长时间游玩稳定性。
2. 确定最终美术质量样板。若采用专门制作的美术资产，需要高低模、贴图、骨骼、动作和多级细节；当前程序化模型可作为轮廓及行为参照。
3. 在当前依附和侵入循环基础上制作不同的可探索区域、污染源结构、宿主遭遇与撤离路线，让身体组合影响具体行动，而不是只改伤害数字。
4. 做不同随机种子的通关率和死亡原因统计，避免早期坏结果直接让玩家无法继续。
5. 用真实玩家观察首次附着是否容易理解、反应堆预警是否清楚、迁移是否有趣、重复流程是否乏味；再完成目标平台打包、输入设备、设置、存档恢复、音效混音和发布前测试。

本轮保持现有 Three.js 工程继续实现，以便用户直接对比修改前后的体验。尚未迁移到其他引擎，也未创建商店页面或发布构建。
