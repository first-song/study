# 异潮 · ABERRANT TIDE

从海洋中的单细胞出发，在可由文字或数字种子生成的大型海域中附着菌膜、搭乘宿主、吞食异化组织并侵入海底反应堆。身体随生态经历与吞噬结果随机发育，最后可以成为巨兽吞没灰屿，也可以上浮到海面寄生人类潜水员并接管岛上控制网络。当前是基于 Three.js 的本地 3D 可玩样片，支持第一、第三视角、桌面与触控。

## V21–V22 灰屿：日本辨识度、岛民与地貌

游戏讲的是"谁在往海里排核污水"，岛如果不一眼看得出是日本，警告的力量就散掉一半。本轮的做法是**不画国旗，改画日常**——国旗是国家的符号，画上去就是在喊话；日文告示牌、渔港名牌、商店街的招牌是"这个地方就是这样"的生活感。

- **日文标识**：排放站「ALPS処理水 排出設備／海域モニタリング実施中」、危险告示「危険／放射線監視中／立入制限」、渔港「松浜漁港／漁業協同組合」、神社「奉納」、商店街「お食事処」「コンビニ／たばこ・お酒」「そば／十割」、路牌「駐車場」。
- **唯一的符号**：港湾旗杆与巡逻舰桅杆上的**日之丸旗**，尺寸很小，要凑近才看得清——它负责确认，而不是喊话。
- **地貌**：岛西北侧新增一座带火山口的**成层火山锥**（上陡下缓、沟壑游走、flatShading、玄武岩色、顶部有火口辉光与蒸汽），与原来的雪山主峰构成双峰。碰撞面未改，地貌纯属视觉。
- **岛民**：围观人群加上领口、反光背心与挎包，帽子按角色缩放（工人黄安全帽、渔民宽檐帽、科学家鸭舌帽）；街上补了自动贩卖机、红色邮筒、白色护栏、商店街雨棚与暖帘。
- **生活细节**：电线杆与垂线、屋顶储水罐与空调外机、塑料大棚、水田、神社参道石灯笼。

## V20 技能成为主线的钥匙

试玩反馈里最要紧的一条是**"技能没起作用"**。原因是技能只是可选项：不用也能通关，玩家自然感觉不到。V20 把技能改成了主线的钥匙：

| 回声体 | 钥匙 | 用错工具 |
| --- | --- | --- |
| 折脊回声体（冲锋型） | 近战：撕咬 / 突进 / 冲刺撞击 | 辐射脉冲只有三成伤害 |
| 诱光群落回声（假光型） | 辐射脉冲打散假光 | 撕咬被假目标骗过，只剩三成五 |
| 压力蠕冠（潜行型） | 按住 X 扫描真身，或按住 C 拟态引它过来 | 两种伤害都只有三成五 |

排放母体的外甲同样挡得住辐射脉冲 —— 触须只能靠近撕。

**不设死锁**：冲刺撞击是近战，任何时候都能用；本能来源也改成按类别保底（捕食型与共生型各保底一个），所以三只回声体永远各有一条路可走，只是快慢差三倍。用错工具时游戏会直接告诉你原因，不会让你干瞪眼。

主线同时加厚：回声体血量翻倍、切断一次要三个窗口；主线合计约 15–18 分钟。

## V18 随机抵达的本能

这一轮把"不好玩"当病来治。三条主线同时推进：

**1. 吞噬的意义从"加数值"变成"解锁新操作"。** 器官仍然随机长出，但每种器官绑定一个能改变打法的主动技能：撕咬（左键）、喷射突进（Z）、辐射脉冲（Q）、拟态（按住 C）、感电扫描（按住 X）。你永远不能指定它们，但你可以决定去哪里猎什么 —— 想拿到撕咬，就去抓甲壳类。完整说明见 `docs/GAMEPLAY_REDESIGN.md`。

**2. 目标不再是读条。** 菌膜会经历摄取—扩张—稳定三段并在稳定期招来捕食者；反应堆入侵分注入—压制—过载三段并会被维护无人机打断；寄生接入会被灰屿电网反击。所有打断都提前给出可读预警，可以自由放弃。

**3. 最后一关变成真正的 Boss。** 排放母体分三阶段：外甲上三条触须要撕断、喷发的污染云要打散或硬扛、核心只在七秒窗口张开。

同时新增**辐射暴走**（高剂量进入伤害提升但持续掉血的状态，结束时释放异变能）与**海洋之息**：左上角的仪表记着你的猎杀与共生，最终决定结局是共潮、灰烬还是深渊之宴 —— 由行为决定，不由菜单决定。

## V17 异变回声追猎

三座活跃反应堆现在分别由折脊回声体、诱光群落回声和压力蠕冠供给共振。玩家必须追踪移动目标，在蓄力后出现的开壳窗口中用辐射脉冲或近距离撕链切断连接；低共振时还可按 E 吞下核心。离开过远会令连接重新生长。

追猎评级根据开壳命中比例与完成速度结算为 1–3 级，并影响生物质与异变能收益，但不会改变“演化结果随机、玩家不能选路线”的规则。海图、雷达、世界边缘标记和具名 HUD 会共同定位当前回声体；完整说明见 `docs/V17_ECHO_HUNT.md`。

## 本轮方向

玩家不选择进化路线或购买器官。身体在成长时自动随机改变，辐射响应也按固定概率结算。玩家决定去哪里、依附谁、何时进入污染源与撤离，无法指定下一次长出什么结构。

食物只维持营养和储能，普通摄食与猎杀不再增加身体发育经验。首次完成不同地点或宿主类型的生态经历才推动发育，重复同一经历不能刷等级。主界面显示下一步行动与已完成经历，移除了原先的吃豆经验条。

海洋中同时存在正常与异常生命。弯脊、骨甲和异位诱饵分别改变身体轮廓、游动或接触能力，并带来代价；它们不是简单换色。动物使用连续网格、程序化表面与游动，场景补充背景鱼群、海底植被和水面动态。本轮内容在项目内构建，没有下载第三方模型或贴图。

主菜单的海域种子接受文字或数字；留空时生成新的随机海域，相同种子会重现相同地图。当前海域直径 640 米，包含六类栖息地。按 J 可打开海图，查看设施、灰屿、海域名与当前位置。

## 一次探索怎样展开

1. **找到菌膜**：初生细胞靠近漂木、礁壁或沉积菌膜，按 G 附着。菌落会经历摄取—扩张—稳定三段，稳定期的气味会招来捕食者：硬撑完成，或者及时脱离。消化完成会推动发育，并且**有机会整合出第一个本能**。
2. **学会用本能**：本能只能随机抵达，但每一条都是能改变打法的操作 —— 撕咬、喷射突进、拟态、感电扫描。想拿到撕咬，就去猎甲壳类；想拿到拟态，就去猎灯笼鱼。你决定去哪，但决定不了抽到哪条。
3. **借助宿主移动**：靠近鱼、鲸或海龟，按 G 搭乘。宿主继续自己的生活路线；保持附着并随它经过足够的时间与距离，形成新的迁移适应。遇到猎手时，慌乱的宿主可能把你甩下来（进度保留，但要重新追上它）。
4. **进入污染源**：三座海底反应堆分别位于沉船、断层与排放站。观察冷却窗口，附着管道侵入；预警后按空格脱离，离开排放水体。入侵分注入—压制—过载三段，压制期会引来维护无人机。
5. **击败排放母体**：三座反应堆停机后，排放母体现身。外甲上的三条触须要用撕咬切下来；断掉后它喷发污染云，用脉冲打散或按住 C 拟态硬扛；最后核心只在七秒窗口张开，趁窗口撕咬或冲刺撞击。
6. **选择实际可达的终局**：Lv.11 巨兽靠近削弱核心按 E 吞岛；或者上浮到灰屿，完成人类潜水员的神经寄生适应，再侵入岛上三处神经中继。两条路线由探索与身体经历解锁，不通过进化菜单选择。

三个菌膜地点、四类宿主和三座反应堆构成十项唯一经历；寄生路线另有三个神经中继。当前目标会根据玩家进入的路线提供引导，但不是让玩家选择器官的菜单。

吞食猎物留下的组织后，每个供体只进行一次随机适应判定。灯笼鱼或鮟鱇可能留下诱光灯器，皇带鱼或深鱿鱼可能留下耐压组织，头足类可能留下喷射腔，甲壳类可能形成复合甲壳，鳐鱼可能留下感电器官；每项最多两阶。击杀本身不给器官。

**器官同时也是主动技能。** 诱光灯器教你拟态，喷射腔教你突进，复合甲壳教你撕咬，感电器官教你扫描，耐压组织保持纯被动。辐射出的膜棘同样教你撕咬，推进器教你突进，发光感知教你拟态，辐射转化强化你的脉冲。**你永远不能指定抽到哪一条。**

这些技能会立刻改变打法：撕咬能打断异变回声体的蓄力；脉冲变成朝向前方的定向扇形并击退致晕；冲刺撞到生物会造成撞击伤害与眩晕；拟态让捕食者几乎锁定不到你，但骗不过回声体的共振；扫描让你在黑暗里看见谁在附近。

## 桌面版（给朋友试玩）

```powershell
npm.cmd run pack:zip      # 生成 dist/异潮-试玩版.zip（约 38MB，内含一个 异潮.exe）
npm.cmd run verify:single # 验证这个 exe 真的能跑、且磁盘上没有明文源码
```

**单文件，双击就玩**：解压后只有 `异潮.exe` 和 `给朋友.txt`。双击后它自己起一个本地服务器，
再用系统自带的 Edge/Chrome 以应用窗口模式打开游戏（无地址栏无标签页）。
游戏文件加密后只放在内存里，**磁盘上不落源码**。
存档在对方自己的 `%APPDATA%\AberrantTide\`。

给朋友的说明写在 `build/给朋友.txt` 里：怎么解压、怎么双击、杀毒软件误报怎么办、
双击没反应怎么办、操作键位、以及一份七条反馈清单。

另有一个 Electron 版本（`npm run pack:win`，约 144MB 的 zip），自带 Chromium 不依赖系统浏览器，适合对方机器上没装 Edge 的情况。

## 启动

双击 `启动游戏.cmd`，或在本目录运行：

```powershell
npm.cmd start
```

然后用 Chrome / Edge 打开 `http://127.0.0.1:4173`。需要 Node.js 20 或更高版本；首次缺少依赖时运行 `npm.cmd install`。不要直接双击 index.html。

## 生物与环境

初始生态目标为 78 条鱼、14 只水母、6 条鲨鱼、6 只鱿鱼、3 头鲸、7 只鳐鱼、5 只海龟、8 条鮟鱇鱼、12 只蟹、24 条灯笼鱼、7 只深层墨鱼和 4 条皇带鱼。总计 174 只参与模拟的海洋动物，实际数量随捕食与补充变化；420 条背景鱼仅承担远景表现。灰屿另有人类潜水员、科研人员、工人、三艘巡逻船、一艘近岸沉船和三类寄生中继。

鱼群会按邻鱼距离做分离、对齐和队形调整，身体转向与摆尾速度随实际游速变化；渲染层对全部动物做固定步长插值，避免远景低帧率批次造成的跳动。鲸类与海龟会上浮换气，鳐鱼在底层滑翔，鮟鱇短距伏击，灯笼鱼群在弱光层游动，皇带鱼以长带状背鳍推进，墨鱼波动裙鳍并喷射逃逸，蟹收集沉降有机物。地形、植被和海洋雪构成不同深度的环境。

海面使用细分动态波形，可与水下互相穿越。玩家上浮到海面后能看到灰屿地形、排放站、灯塔、码头、船只和人类活动；这些实体在海面已进入可探索距离后显示完整模型。

海面巡逻船会循环发出黄色预警和声呐冲击。暴露在水面的细胞会被压向深处并损失能量；可以下潜规避，也可以追进船尾尾流获得推进。水下贴近至少三条同向、无强光的鱼时可以融入鱼群，降低大型捕食者的发现距离。近岸海底新增可摆动的海葵、管状海绵、发光滤食扇和人类科研船残骸。

营养由有机食物和菌膜交换补充，缺乏营养会影响恢复与游动；同位素不提供有机营养或身体成长经验。5 级后可捕食小型动物，7 级后可挑战更大的猎物；鲸类作为生态巨兽，不参与玩家战斗。

异常个体有弯脊、骨甲增生和异位诱饵三种表型。游速、防护和攻击不同，污染区域的暴露会参与表型变化。图鉴单列异常生命，附近观察栏也会显示其身体变化和代价。发光不能单独作为污染标记；快速重塑、强化骨甲和额外器官均属于本作的科幻设定。

## 自动随机演化

- 身体成长：首次完成生态经历后自动发育，从尚未满阶的吞噬、辐射、共生特征中等概率产生变化。游戏不会暂停让玩家选择，重复吃食或猎杀也不会推动等级。
- 辐射响应：每积累 32 异变能自动结算一次。70% 产生结构变化，30% 仅发生适应。成功后从未满阶的六类器官中等概率抽取；每种两阶。
- 六类器官：耐辐膜层、增生推进器、发光感知、辐射转化、异化膜棘、共生修复。均有实际效果及生存代价。
- 辐射负荷独立计算，超过耐受阈值会持续损伤生命。一次响应不会清除负荷。
- M 面板显示最近 12 次辐射响应、已经形成的结构以及下一次事件的系统概率。没有购买、指定路线或调整概率的按钮。
- 随机数状态保存在存档中；从同一存档执行相同的后续操作会重现相同随机结果。

身体结构在等级 1、3、5、7 进入单细胞、协作细胞群、多细胞幼体和分化异化体阶段，等级 11 成为深渊巨兽。具体特征组合与吞噬器官随随机结果改变，玩家不能指定路线。

## 海洋之息

左上角的仪表记着你这一局的账：共生里程碑让它变宽，猎杀让它变窄，把某个物种打到近乎绝迹会让它猛地一沉。这个账不是分数，是**你这局扮演了什么样的生命**。

它会立刻回应你：账目越负，捕食者发现你的距离越长、鱼群离你越远、水色越浑浊；账目越正，情况反过来。

它也决定结局 —— 与你走的是巨兽路线还是寄生路线无关：

| 账目 | 结局 | 内容 |
| --- | --- | --- |
| ≥ +20 | **共潮** | 灰屿灯火熄灭，海水重新变蓝 |
| −20 ~ +20 | **灰烬** | 你赢了，但什么都没改变 —— 岛沉了，海还是死了 |
| ≤ −20 | **深渊之宴** | 你吞了岛，也吞了海洋；海水开始变黑，那是你 |

**你的成长就是海洋的死亡**，这句话不需要写在游戏里 —— 玩家自己会看见。

## 存档

自动保存和暂停菜单手动保存均使用当前浏览器的 localStorage。存档格式 v7，兼容 v1–v6。旧档保留等级、器官和世界种子兼容信息，补充菌膜、宿主、反应堆及灰屿寄生网络；后续摄食不再增加经验。v7 同时保存吞噬供体判定、终局类型、寄生中继进度和海域几何，避免读档重抽器官或把设施移入另一张地图。等级上限为 13。

同一浏览器、同一地址和端口可继续进度。清除网站数据、无痕窗口或更换浏览器会影响存档。

## 验证

```powershell
npm.cmd test
node scripts/verify-instincts.mjs
node scripts/verify-mother.mjs
node scripts/smoke.mjs
```

第二条命令要求服务已运行，并使用已安装的 Chrome / Edge。测试产物放在 artifacts/。浏览器回归同时检查巨兽吞岛和寄生接管两条终局；后期场景使用明确的测试状态，因此截图通过不等于完整人工通关；引擎另有自动从出生到终局的模拟测试。

故事中的灰屿为虚构岛屿。智慧觉醒、辐射转化与单局内快速演化属于科幻，海洋深度和微观／宏观视觉比例被压缩。这不是自然演化模拟器。
